# Pinterest 파티클 갤러리 🎨

마우스 커서를 따라다니는 미리보기 패널과 추상적인 입자 애니메이션을 특징으로 하는 인터랙티브 웹 갤러리입니다.

## 기능

✨ **동적 파티클 애니메이션**
- 다양한 기하학적 형태(큐브, 구, 정십이면체 등)의 입자들이 랜덤하게 생성되고 부유합니다
- 각 입자는 고유한 회전 속도와 이동 벡터를 가집니다
- 화면 경계에서 자연스럽게 반사됩니다

🖱️ **마우스 인터랙션**
- 입자 위에 마우스를 올리면 해당 이미지의 미리보기가 하단에 표시됩니다
- 미리보기 패널은 마우스 위치를 부드럽게 따라다닙니다
- 입자가 커지면서 강조 효과가 나타납니다

🖼️ **이미지 확대 뷰**
- 입자를 클릭하면 모달 창에서 전체 이미지를 볼 수 있습니다
- 이미지에 자동으로 생성된 태그와 설명이 함께 표시됩니다
- 모달 배경을 클릭하거나 닫기 버튼으로 닫을 수 있습니다

## 기술 스택

- **Three.js**: 3D 그래픽 및 파티클 애니메이션
- **Vanilla JavaScript**: 순수 자바스크립트로 인터랙션 처리
- **WebGL**: 고성능 렌더링

## 파일 구조

```
pinterest-particle-gallery/
├── index.html          # 메인 HTML 구조
├── style.css           # 스타일 및 애니메이션
├── script.js           # Three.js 파티클 시스템 및 인터랙션
├── data.js             # 샘플 Pinterest 핀 데이터
└── README.md           # 프로젝트 설명서
```

## 실행 방법

1. `index.html` 파일을 브라우저에서 직접 열거나
2. 로컬 웹 서버를 사용하여 실행합니다:

```bash
# Python 3
python -m http.server 8000

# 또는 Node.js (http-server)
npx http-server
```

그 후 브라우저에서 `http://localhost:8000` 또는 `http://localhost:5500`에 접속합니다.

## 사용자 가이드

1. **미리보기 보기**: 마우스를 입자 위로 움직입니다
2. **미리보기 팝업**: 하단 중앙에 작은 미리보기 패널이 나타납니다
3. **이미지 확대**: 입자를 클릭하여 전체 이미지를 확인합니다
4. **태그 보기**: 확대 뷰에서 자동 생성된 태그를 확인합니다
